| But let’s stay with the alert. Suppose the system estimates a _30% chance_ that it’s an attack. “Benign” is the more likely label. Does that mean we should allow the activity? | Not necessarily. For a simplified example, say a missed attack costs $100, a false block costs $10, and blocking an attack prevents it at no cost. Allowing the activity has an expected loss of $30 (30% of $100); blocking it has an expected loss of $7 (70% of $10). The same prediction leads to different choices when we change the costs.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |     |

| **So how do reasoning and decision models fit together?** For our alert, GLiNER could return labels like “new device” and “unusual login.” If the evidence is unclear, a reasoning model could examine the logs and suggest a response; Strands could then choose among “allow,” “review,” and “block.”                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |     |
| These roles overlap: reasoning models make decisions, and some decision models reason before choosing. A world model can help explore possible outcomes; causal reasoning asks what difference an action made. And, as we’ll see, one model’s reasoning can help train another to make a faster judgment.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |     |
