# Hugging Face - State of Open Models Summer 2026

## Summary

Hugging Face uses Hub activity to describe an open-model ecosystem in which frontier-scale releases coexist with overwhelming practical demand for small models. It distinguishes public attention from operational adoption and argues that derivative ecosystems, local inference tooling, and agent traffic increasingly determine where open-model value accumulates.

## Key claims

- Likes and downloads measure different phenomena; the most discussed repositories rarely match the most downloaded dependencies.
- Qwen's large derivative ecosystem makes it a substrate for downstream adaptation, not merely a family of checkpoints.
- Models below one billion parameters dominate aggregate downloads, despite attention around very large MoE releases.
- Quantization and runtimes such as llama.cpp expand the set of models that can be used locally.
- Automated agents increasingly account for Hub downloads and repository interaction.

## Why it matters

The article motivates [[Open Model Ecosystems]] as a systems concept spanning licenses, derivatives, runtimes, model size, and machine-driven consumption.

## Tensions / open questions

- Hub downloads do not measure private deployment, hosted API usage, or successful production adoption.
- Parameter counts and license labels alone do not establish practical openness.
- The figures are a time-sensitive snapshot and should not be treated as stable market shares.
