| ## Why Image-Aware Memory Matters                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Persistent memory makes agents useful across turns and sessions, but many enterprise workflows are not text-only. A customer may attach a screenshot showing an error state. A field technician may upload a product image. A finance workflow may include a receipt. If the memory layer only stores text, the agent can lose visual evidence that may be important for a later decision. For example, a later support turn may refer back to a previously observed error state, but without the original visual context the agent may no longer have the evidence needed to interpret that reference correctly.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Image-aware memory addresses that gap by turning visual evidence into durable context. The important design choice is that the system does not need to return raw bytes in every retrieval. It can store bytes in the database, search through a text representation, and hydrate bytes only when an application explicitly asks.
