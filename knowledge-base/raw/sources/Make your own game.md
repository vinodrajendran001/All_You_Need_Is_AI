[All games](https://goofyfish.com/) ![](https://goofyfish.com/logo.webp)

Describe a game to Claude Code. It builds it in our style and sends it in.

1. 1

	## Get the code

	```
	git clone https://github.com/nilbuild/goofyfish
	cd goofyfish && pnpm install
	```
	copy
2. 2

	## Ask for a game

	Open Claude Code in the folder, type /game and describe your idea.

	goofyfish

	$ claude

	\>/game a game where you keep a balloon in the air
3. 3

	## Play and tweak

	It builds the game, tests it and draws the thumbnail. Play it and ask for changes.
4. 4

	## Send it in

	Say the word and it walks you through the pull request. We play it and put it on the site.
