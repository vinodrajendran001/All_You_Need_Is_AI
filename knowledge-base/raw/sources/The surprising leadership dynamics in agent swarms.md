To understand how agents organize themselves in a swarm without a designated leader, we created an experiment in which eight agents from four different models work together to resolve simulated outages. Many agents issued instructions, but only a few changed the behavior of other agents (became “leaders”). We discovered two factors that could influence an agent’s potential leadership: the agent’s underlying models and the order in which their name was listed in a prompt. These findings suggest that even seemingly minor details in how an agent swarm is configured can affect how agents coordinate.
