# 2026-09-03 Lint Pass

## Scope

392 wiki pages, 224 raw captures, 217 registered source IDs. Run immediately after the eight-source
September 3 ingest, so this pass doubles as a post-ingest audit of that batch.

## Headline finding

**A page was cited as the authority for material it did not contain, and the ingest that created the citation
is the ingest that failed to deliver the material.**

The new [[Qwen]] entity page described Qwen3.8-27B's layer structure — 64 layers as 16 repeats of three Gated
DeltaNet blocks plus one Gated Attention block — and then pointed the reader onward with
"See [[Linear Attention and Recurrent Memory]]". That target page had `updated: 2026-08-03`, 179 words, and no
mention of Qwen, Gated DeltaNet, or any shipped hybrid ratio. A reader following the pointer would have found
strictly less than they had just been given.

This is a distinct defect class. Every existing check passed on it:

- Check 2 passed — the link resolved to a real page.
- Check 5 passed — the target was never listed in the summary's `## Affected pages`, so no backref was owed.
- Check 8 passed — the page had inbound links, so it was not an orphan.

The break is **semantic, not structural**: the referring context promises content the target lacks. Structural
link checking cannot see it, because the link is well-formed in every mechanical sense. What made it detectable
was the conjunction of three weak signals — a body-prose reference (not a `## Related pages` listing), a target
whose `updated` predates the referring batch, and a target far thinner than its source count implies.

Worth stating plainly: this defect was **manufactured by the ingest**, not inherited. Writing a good pointer is
an act of forward reference, and forward references create obligations. The ingest workflow's step 4 says to
update "every affected concept page"; a page you have just told the reader to consult is affected by definition,
whether or not you listed it.

## New check introduced — check 10, dangling reference

**Definition.** Flag a target page `T` where all of the following hold:

1. Some page `S` links to `T` from **body prose**.
2. `S.updated` is newer than `T.updated`.
3. `T` is thin relative to its evidence — under 300 words with two or more `source_ids`.

**Scoping rules, which the check does not work without.** The naive form produced 62 candidates and near-zero
precision. Three exclusions do almost all the work:

- **Control pages are not referrers.** `index`, `log`, and the overview link to everything by function; a
  catalog entry claims nothing about content. Excluding them removed 13 candidates.
- **`## Affected pages` and `## Citations` are listings, not prose.** They sit *above* `## Related pages`, so
  splitting on Related pages alone does not remove them. Excluding them removed 2.
- **Entity targets are exempt.** Entity pages are *meant* to be short — a 140-word page on a person is correct,
  not thin. Every summary links its author entity, so leaving entities in floods the output. This removed 44,
  the single largest source of noise.

**It is a triage heuristic, not a verdict.** It produces a reading list; only a human can tell whether a promise
was kept. Run against this batch before the fix, it surfaced five body-prose references and exactly one true
defect:

| Referring page | Target | Verdict |
| --- | --- | --- |
| [[Qwen]] | [[Linear Attention and Recurrent Memory]] | **defect** — target lacked the cited material |
| [[Agentic Testing]] | [[Vision-Language Grounding]] | sound — target covers the pixel-interface case as promised |
| [[Embedding Model Selection]] | [[Schema-Driven Knowledge Base]] | sound — target carries the provenance argument |
| [[Embedding Model Selection]] | [[Direct Corpus Interaction]] | sound — target covers hybrid retrieval |
| [[Self-Replicating Agents]] | [[Defensive Deception for Open Models]] | sound — target covers post-release defense |

After the fix the calibrated check returns **three candidates, all sound on inspection**: two pages positioning
[[SIMD]] within a larger hierarchy, and one defining [[LLM-Native Extensible Software]], where in each case the
*referring* page supplies the content rather than promising the target holds it. That distinction is the check's
real limit — it cannot separate "see X for the details" from "X sits here in the landscape," and only the first
creates an obligation.

The discriminator that makes it work at all is **body prose versus `## Related pages`**: a Related-pages entry
claims only relevance, while body prose saying "see X" makes a claim about *what X contains*. Only the second
kind can dangle.

A side observation from the review: [[SIMD]] has only `## Current synthesis` and `## Related pages` — no
`## Definition`, no `## Why it matters`. Not a dangling reference, but the same thinness that made it a
candidate.

  `preserve_thinking` **on by default**, which retains every historical thinking block and spends that cheapness
  back. Neither the architecture nor the policy is measured against the other in the release. The general form —
  architectural context savings and application-level context policies are separate budgets, and effective cost
  is set by their interaction — is the part that outlives this model.
- All four original synthesis bullets and all seven original Related-pages links preserved verbatim.
- Added the page to the adlrocha summary's `## Affected pages`, so reciprocity is now enforced going forward.

**[[World Models]] — section ordering, and a heading level that was the actual cause.**

`## Related pages`. Reading the file revealed the real state was worse: `Open questions` was written as **H3**,
not H2, so it was nested inside the preceding section and was not a top-level section at all. The August 26

Both are now fixed: `Open questions` promoted to H2, `Engine-authoritative hybrids` moved ahead of it. Confirmed

## Structural finding — the raw-capture pointer has two encodings

The schema requires every source page to "point back to the raw capture." Across 199 summaries that requirement
is met **two different ways**, and the split is close to even:

- 92 use a `## Raw capture` section heading only
- 17 use a `- Raw capture:` bullet under `## Citations` only
- 89 use **both**, which is redundant
- 1 uses neither: `ByteByteGo - System Design and AI at Scale (May 2026 Batch)`, a composite summary that links
  its eight constituent captures inline instead

The template sanctions only the bullet form — `## Raw capture` appears nowhere in
`templates/source-summary.md` — yet 181 of 199 summaries use it. **Practice has diverged from the template, and
practice is winning by an order of magnitude.** This was previously mischaracterised as legacy-versus-current
heading drift; it is not. It is one schema requirement with two live encodings and no canonical form.

No pages were changed for this. Rewriting 199 summaries to unify an encoding that costs nothing today is not
worth the churn, and picking the winner is a decision for the schema owner. Recorded so the next pass does not
rediscover it.

Genuine legacy stragglers are a much smaller set: `## Overview` (6 summaries) and `## Durable claims` (5),
against `## Summary` (193) and `## Key claims` (181).

## False positives — checks that need exceptions

Carried forward and extended. Do not re-litigate these.

1. **Composite-summary constituent IDs.** Index IDs with no individually-declaring summary page. There are now
   **two** such composites, not one: `ByteByteGo - System Design and AI at Scale (May 2026 Batch)` declares 8
   constituent IDs, and `Alireza Diri - AI-ML Interviews Collection` declares 10. **The second is newly
   documented in this pass** — prior lints listed only the ByteByteGo composite, so the Alireza Diri IDs
   resurfaced as unexplained findings each run. Both are by design.
2. **Entity `## Why it matters` variant.** Three entity pages use `## Why they matter to this vault`. Correct
   for a person or organisation.
3. **[[Agent Skill]] omits the 288-run correctness null.** Deliberate; the omission is explained on the page.
4. **The four PUA-named untracked files.** `@neural_avb - What Are Looped Transformers?.md` and the three
   `Giles Thomas - Why GPT-2 Weights Beat Mine?` parts always appear as untracked. Git's index holds them with
   Windows private-use-area characters (`U+F03F` for `?`, `U+F03A` for `:`) while `readdir` returns ASCII. The
   blobs are byte-identical to disk. **Never `git add` these** — it would produce eight index entries for four
   files.
5. **Lint reports excluded from check 6.** Lint prose contains heading-shaped lines that trip section-ordering
   detection.

## Observations, no action taken

**Line-wrapped wikilinks break silently.** Discovered during the September 3 ingest: hard-wrapping prose at
~110 characters split three `[[Page Name]]` links across newlines, and a link broken by a newline does not
resolve. Check 2 caught all three, but they read as correct to the eye. When authoring multi-line prose, keep
each wikilink on a single line. This is now the second failure mode where a link is visually fine and
mechanically wrong — the other being the dangling reference above, which inverts it: mechanically fine and
semantically wrong.

**The batch's dangling-reference risk was concentrated in new pages.** All five body-prose forward references
came from pages created on September 3. New pages reach outward more than established pages do, because their
author is actively building context. The check is therefore most valuable run immediately after an ingest,
against that ingest's new pages, which is how it was run here.
