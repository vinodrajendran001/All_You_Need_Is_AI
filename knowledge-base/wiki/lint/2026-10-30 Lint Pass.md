# 2026-10-30 Lint Pass

## Scope

Forty-fifth pass, following the October 30 ingest. The starting inventory was **637 typed wiki
pages**. Adding this report leaves **638**, including **342 source summaries**, **137 concepts**,
**95 entities**, and **45 lint reports**, with **368 owned source IDs**. Local-only query files
are excluded.

Structural coverage included frontmatter and directory/type agreement, source ownership,
index/log/overview parity, wikilink resolution, reachability, index categories, Related-pages
endings, source-summary sections, source/post/query boundaries, and affected-page/body-citation
reciprocity. A supplementary survey checked naming and canonical metadata across all **372
top-level raw captures**.

Semantic review covered the seven recent source chains and their additions across **32
concept/entity consumers**, then followed specific catalog claims and the previous pass's
deferred routing links into captured evidence. It did **not** independently revalidate every
claim in all 342 source summaries, reproduce benchmarks, execute captured code, or fetch
external papers.

The preservation baseline was the working tree after the completed ingest, not Git HEAD.
Native Windows read-only snapshots and hash-verified Markdown mirrors avoided the WSL file-read
stalls encountered during this session.

## Findings

### Clean graph, but some claims lost their measurement boundaries

The standing structural audit returned zero findings before and after the fixes. All **638
pages** are reachable afterward; index, log, and overview retain exact **368-ID** parity.
Reciprocity is **A 0 / B 0 / C 0**: affected consumers own the source ID, owning summaries list
their consumers, and source citations in consumer body prose have matching ownership.

That graph did not catch several semantic overclaims:

- **MemoryTax:** the index and overview generalized a cost win across raw-record coding
  harnesses. In [[Alpha Signal - The Hidden Memory Tax in AI Agents]], only Pi was cheaper
  than full context with Opus 5.5; Codex and Claude Code cost more. The harnesses also received
  photo captions unavailable to other methods. The controls now retain the unequal-access,
  single-conversation, single-run, model-judge limitations.
- **Cohere serving:** [[Cohere - North Mini Code Megakernel Serving Engine]],
  [[Megakernels]], and [[Inference Serving Engines]] incorrectly inferred that no mixed
  prefill/decode meant no continuous batching. The capture explicitly supports continuous
  batching, paged attention, and ragged sequence lengths; ordinary PyTorch prefill pauses
  decoding. The batch-size-8 configuration limit remains.
- **Cohere metrics:** the source summary, those two concepts, [[Cohere]], and the overview
  called the full-server result an unspecified end-to-end speedup. It is an **average
  decode-throughput ratio**, with different generated token counts. Separate context-scaling
  and SciCode accuracy checks must not become a universal performance/quality guarantee.

The LiveCodeBench v6 table in the Cohere capture makes the distinction concrete:

| Engine | Generated tokens | Total time, seconds | Reported average decode throughput, tok/s |
| --- | --- | --- | --- |
| Megakernel | 4,933,421 | 6,141 | 803 |
| vLLM | 3,394,164 | 5,428 | 625 |

The reported **1.28x** throughput ratio coexists with a longer total run. It is not a
matched-work completion-time improvement. [[Serving Benchmarks and Goodput]] now carries
this example, while the other consumers label the **1.25x-1.41x** full-server range precisely.
The controls also attribute Cohere's priority claim to its authors, and the index now says
one persistent kernel with one **threadblock** per SM, not one kernel per SM.

### A small benchmark and a deterministic boundary became universal guarantees

[[Sebastian Raschka - Using Local Coding Agents]], [[Coding Agent Harness]], and [[Model Routing]]
turned a small-task observation into a rule that token use depends on the harness, not the
model. Raschka observed similar use within a harness among models solving almost all tasks;
Gemma's low use accompanied early failures. His suggested doubling of speed from halving
tokens is an extrapolation, not a matched wall-time result. The revised pages distinguish
input volume, task success, model-dependent behavior, and elapsed time.

[[Model Routing]] also claimed that Meta's deterministic router has zero latency and no
injection surface, and that model changes cannot invalidate its decisions.
[[Plawan Rath et al - The Thin Orchestrator]] supports removing routing-model inference,
not eliminating instruction-file reads, state checks, input gathering, reliability gates,
maintenance, or ordinary input-handling risks. Fixed mappings still need validation as
workflows and destination capabilities change. Specialist/workflow routing remains distinct
from cost-tier selection, and Meta's results remain self-reported and unablated.

### Recent-ingest slips and two deferred links

- [[Continual Learning for Agents]] called OPST's topic seeds generated. They are hand-selected
  descriptors; questions are generated. [[Leon Sick et al - On-Policy Self-Training]] already
  preserved this distinction, alongside mixed retention and the teacher/student roles.
- [[Software Performance Engineering]] inferred a lower cost of proposing candidates from
  [[Pavi Dhiman and Cyrus Asgari - Building an Inference Stack That Improves Itself]].
  The source reports automated experimentation and endpoint gains, not an all-in proposal-cost
  comparison. The generalization is now experimental discipline for automated candidates.
- The index's [[Tool Use and Function Calling]] description still assumed external execution.
  It now separates action syntax, the actual executor, and authorization, consistent with the
  compiled internal executor described by [[Divyansh Agrawal - Qwenputer - A Deterministic RISC-V CPU Inside Qwen3.5]].
- [[Agentic Testing]] now links directly to
  [[Cloudflare - Cutting Our Inference Bill by 68% by Being Obsessive About Optimization]].
  A next-push edit to flagged lines is an action proxy, not a correctness verdict or recall
  measure; lines 30 to 40 away changed about 15% of the time. The concept owns the existing
  Cloudflare ID, and the summary lists it under both Affected and Related pages.
- [[Model Routing]] now links to [[Latent-Space Reasoning]] in Related pages. This closes the
  other navigation follow-up from [[2026-10-27 Lint Pass]] without importing a new numerical claim.

### Two source-section orders and one unsupported capture date

[[Giles Thomas - Why GPT-2 Weights Beat Mine Part 2 - Bugfix]] and
[[Siddhant Rai - Jev - Models Built for Decisions Rather Than Text]] placed Why it matters
after Tensions / open questions. Their existing sections were moved without changing the
section text. Rai's separate evaluation-evidence section remains in place. Older provenance
layouts, including raw pointers under Citations, were not mass-reordered.

The Thin Orchestrator summary previously asserted a **2026-10-22** capture date. Its raw
clipper metadata instead contains **created: 2026-10-21**. The citation now names that field
explicitly rather than asserting an independently established capture timestamp. The raw
metadata was not changed.

### Raw-schema gaps extend beyond undated filenames

Of **372 top-level captures**, **86** have undated filenames: the previously reported 79
plus the seven recent captures. **81** retain clipper frontmatter and **5** have none.
All 86 lack the canonical `type`, `source_id`, and `captured` fields.

The broader survey found **181 captures** missing at least one canonical raw field,
including **95 with dated filenames**:

| Missing canonical field | Captures |
| --- | --- |
| `url` | 181 |
| `captured` | 153 |
| `source_id` | 134 |
| `type` | 88 |
| `title` | 5 |
| `author` | 5 |

These are field-name/schema gaps, not necessarily lost provenance. **176 of the 181 missing
`url` have a `source` URL alias.** A dated filename alone did not guarantee complete metadata.
No raw capture was renamed or normalized: those changes require explicit authorization.
