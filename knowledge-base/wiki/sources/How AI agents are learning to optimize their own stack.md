| Researchers are enabling AI agents to self-improve by rewriting the software and the models that power them. The goal is to remove the bottleneck of manually tuning agents with an automated loop driven by execution feedback.<br><br>The main target is the agent harness, the layer around a model that includes prompts, tools, memory, context management and control flow. These components determine what the model sees, what actions it can take and how it handles failures.<br><br>But the emerging self-improving agentic frameworks also work on fine-tuning the backbone model along with the agent, reshape training environments, and redesign how multiple agents work together.<br><br>The emerging approaches are not stages in a hierarchy, and they often overlap. But most follow a similar pattern: run tasks, collect execution traces, find recurring weaknesses, modify part of the stack, then test whether the new version is better.<br><br>**Skills: Make the agent’s instructions trainable**<br><br>Skills are one of the easiest places to start. They are usually text files that package task-specific instructions, workflows and heuristics outside the model weights. [Microsoft’s SkillOpt](https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=ovzHFXBkY1O8kSr9&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e "https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=ovzHFXBkY1O8kSr9&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e") turns the skill document itself into the object being optimized.<br><br>SkillOpt evaluates the agent on a set of tasks. It then analyzes the scored trajectories and proposes small additions, deletions or replacements to the skill file. It then tests the candidate on a held-out validation set, which contains examples that were not used to generate the edit. A suggested modification is only accepted if it improves the validation score.<br><br>![alpha_signal_image_1](https://alphasignal.ai/image/1791120613451-32du2y.png)<br><br>Google Research’s [WikiSkill](https://alphasignal.ai/news/self-improving-ai-skills-learn-in-the-notebook-not-the-file "https://alphasignal.ai/news/self-improving-ai-skills-learn-in-the-notebook-not-the-file") addresses another problem: the information needed to optimize skill files is scattered across different components. WikiSkill creates a wiki that gathers the agent’s experience (both successes and failures) into a structured format.<br><br>The wiki sits as an intermediate layer between raw execution traces and the executable skills used by the agent. WikiSkills uses this information to iterate over skills and avoid rediscovering the same problems and retrying rejected fixes.<br><br>![alpha_signal_image_2](https://alphasignal.ai/image/1791120716845-mqq7by.png)<br><br>Skills are a good first optimization surface when the agent has the right tools and general workflow but repeatedly makes procedural mistakes. The model stays fixed, and the result remains a compact artifact that developers can inspect, version and deploy like other agent instructions.<br><br>**When skills aren’t enough: Let the harness rewrite itself**<br><br>Some failures are caused by deeper problems in the runtime components surrounding the agent. An agent might retry the same broken command, fail to verify its work or mishandle state between tool calls.<br><br>[Self-Harness](https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=QsMLt2U6ZDjyaGXw&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e "https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=QsMLt2U6ZDjyaGXw&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e") expands the editable surface beyond instructions. It mines execution traces for recurring weaknesses, proposes targeted harness changes and uses regression tests to make sure improvements on one task does not break performance on others.<br><br>![alpha_signal_image_3](https://alphasignal.ai/image/1791120777796-gq390o.png)<br><br>In experiments with three model families on Terminal-Bench-2.0, SWE-bench Verified, and AppWorld, Self-Harness made impressive improvements, with relative gains reaching 132%.<br><br>The [Darwin Gödel Machine](https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=113rQqrK9dr6cz77k&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e "https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=113rQqrK9dr6cz77k&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e") (DGM) takes a more open-ended approach. A coding agent modifies its own implementation, tests the descendant and stores different variants in an archive. Instead of following one best-so-far chain, it can return to older versions and explore different paths.<br><br>DGM works mainly for coding agents: its target task is coding, and improving itself is also a coding task. [Hyperagents](https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=1B8UJ8RTroGEKFTKu&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e "https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=1B8UJ8RTroGEKFTKu&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e") by Meta extends the idea to domains where that alignment does not exist.<br><br>It combines a task agent with a meta-agent responsible for changing it in one editable program. The modification process itself can evolve, and experiments showed mechanisms such as persistent memory and performance tracking emerging during the search.<br><br>![alpha_signal_image_4](https://alphasignal.ai/image/1791120809024-9cc0vp.png)<br><br>The progression expands the optimization surface from instructions, to runtime behavior, to the machinery that generates the next improvement.<br><br>**Model-harness co-evolution: Let each side teach the other**<br><br>Xiaomi’s [HarnessX](https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=ujiRtveGEjKd6YvI&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e "https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=ujiRtveGEjKd6YvI&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e") introduces the idea of model-harness co-evolution. It uses execution traces to evolve the harness. But the same trajectories can also become training data for the underlying model.<br><br>Better harnesses expose strategies that the model can learn to internalize. The updated model then produces new behavior that provides evidence for another round of harness optimization. A model that is fine-tuned on harness trajectories will be able to perform tasks more efficiently and with fewer input tokens.<br><br>Note that model-harness co-evolution only applies to open-weight models rather than proprietary models available only through an API.<br><br>![alpha_signal_image_5](https://alphasignal.ai/image/1791120641880-o1dpek.png)<br><br>The tradeoff is cost and complexity. Harness-only evolution can operate around a frozen model. Model-harness co-evolution adds training-data generation, training compute, model versioning and another evaluation loop to make sure the updated model still works well with its harness.<br><br>**Optimize the other side of the loop**<br><br>Agent developers usually focus on improving the harness. [EnvHarness](https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=MALvzuQxut0y9Tb3&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e "https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=MALvzuQxut0y9Tb3&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e") suggests that the environment it learns from should evolve too. Training environments are expensive to build and often remain static, making them ineffective after the agent masters their tasks.<br><br>EnvHarness wraps an existing environment with programmable components without changing its underlying logic or verifier. An LLM-based designer reads the agent’s trajectories, diagnoses weaknesses and writes components that change parts of the experience, such as starting conditions, observations or available actions. The loop can repeat as the agent improves and new weaknesses emerge.<br><br>![alpha_signal_image_6](https://alphasignal.ai/image/1791120689831-ttihva.png)<br><br>Across five benchmarks, agents learning in EnvHarness environments improved by up to nine points on held-out tasks while using about 9.8% fewer interaction steps. For applications where the agent has exhausted the useful lessons in a static set of tasks, the next optimization target can therefore be the experience the agent receives.<br><br>**Beyond one agent: Evolving the orchestration layer**<br><br>The same optimization idea can move above individual agents. EverMind AI’s [Raven](https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=AMXaSIyIAdQuHyrr&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e "https://app.alphasignal.ai/c?uid=12PIFGaVBFKQnaUyy&cid=be126abd100b101e&lid=AMXaSIyIAdQuHyrr&mid=428e59b0-3b44-498f-ac2b-973b5fcb7d0e") applies it to multi-agent systems. Its host agent can break a goal into subtasks, assign them to specialized agents, coordinate dependencies and integrate the results.<br><br>Raven can also evolve model- and domain-specific harnesses based on benchmark feedback. The system can improve both the agents that perform individual tasks and the way those agents are assembled to solve larger problems.<br><br>![alpha_signal_image_7](https://alphasignal.ai/image/1791120565549-zjt0u8.png)<br><br>**Which part of your agent stack should evolve first?**<br><br>The practical rule is to start with the narrowest optimization surface that contains the bottleneck:<br><br>- If the runtime works but the agent repeatedly makes procedural mistakes, **optimize the skills**.<br>- If failures come from tool use, context management, memory, verification or control flow, **optimize the harness**.<br>- If the harness repeatedly discovers strategies the model cannot execute reliably, **consider model-harness co-evolution**.<br>- If the agent has stopped learning enough from a static training setup, **optimize the environment**.<br>- If specialized agents work well individually but coordination is the bottleneck, **optimize the orchestration layer**.<br><br>As more of the agent stack becomes editable, developers will spend less time deciding every improvement manually and more time deciding what can change, what must remain fixed and how improvement will be measured. |
